# Retail AI Analytics System

## Overview

The Retail AI Analytics System is a distributed retail management application developed using Java technologies. The system enables businesses to manage product information, analyze sales data, monitor inventory levels, and generate data-driven insights to support decision-making.

The application follows a **Client-Server Architecture**, where users interact through a graphical interface, while business logic and database operations are handled on the server side. Communication between the client and server is achieved using **Java Remote Method Invocation (RMI)**, allowing seamless remote access to retail services.

## Key Features

* Product management and inventory tracking
* Sales data storage and retrieval
* Retail analytics and reporting
* Sales prediction based on historical data
* Low stock monitoring and alerts
* Distributed client-server communication
* User-friendly graphical interface

## Technologies Used

* **Java SE 21** – Core application development
* **JavaFX** – Graphical User Interface (GUI)
* **JDBC (Java Database Connectivity)** – Database integration
* **Java RMI (Remote Method Invocation)** – Client-server communication
* **JavaBeans** – Data encapsulation and transfer between layers
* **MySQL** – Relational database management
* **Eclipse IDE** – Development environment

## System Architecture

The system is designed using a multi-tier architecture:

* **Presentation Layer:** JavaFX-based user interface
* **Business Logic Layer:** RMI server handling application logic and analytics
* **Data Access Layer:** JDBC-based database operations
* **Database Layer:** MySQL database for persistent storage

This architecture promotes modularity, scalability, and maintainability.

## Analytics Capabilities

The analytics component processes retail sales data to provide useful business insights, including:

* Sales trend analysis
* Product performance evaluation
* Best-selling product identification
* Inventory status monitoring
* Basic sales forecasting using historical transaction data

## Project Objectives

* Demonstrate the implementation of distributed systems using Java RMI
* Integrate Java applications with relational databases through JDBC
* Apply JavaBeans for structured data management
* Develop an interactive desktop application using JavaFX
* Provide analytical insights for retail operations through data processing techniques

This project showcases practical implementation of:

* Distributed computing concepts
* Client-server communication

## Conclusion

The Retail AI Analytics System combines multiple Java technologies to create a complete retail management and analytics platform. By integrating JavaFX, JDBC, JavaBeans, RMI, and MySQL, the project demonstrates how modern enterprise applications can support operational management and data-driven decision-making within a retail environment.
